# Project context

Before doing anything in this project, read these files in order:

1. `AGENTS.md`: project rules and the POC feature list (the source of truth).
2. `docs/PROJECT_STATUS.md`: what is built, what is left, and decisions made so far.
3. `CONTRIBUTING.md`: file ownership, data shapes, git workflow.

Keep `docs/PROJECT_STATUS.md` up to date when you finish something.
This file only points to the others, so there is a single source of truth.
